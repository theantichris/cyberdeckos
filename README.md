# CyberdeckOS

My cyberdeck inspired dotfiles for all my devices. Files are managed by [[chezmoi]](https://www.chezmoi.io/)

## Systems

These are the devices and operating systems supported.

| System    | OS      |
|-----------|---------|
| tranchion | CachyOS |

## Package Registry

A registry of installed packages are at [packages.yaml](./.chezmoidata/packages.yaml).

## Default Applications

| System    | Type         | Application  |
|-----------|--------------|--------------|
| tranchion | browser      | Brave Origin |
| tranchion | desktop      | Hyprland     |
| tranchion | editor       | Mitos        |
| tranchion | file manager | superfile    |
| tranchion | terminal     | kitty        |
